Material Crosswalk Upload Template - Instructions
================================================
Material Crosswalk Upload template.

LEGEND:
- M = Mandatory
- O = Optional
- Text = Letters and symbols allowed
- Alphanumeric = Letters and numbers
- Numeric = Numbers only
- Value Set = Limited to specific allowed values

--------------------------------------------------
FIELD-BY-FIELD INSTRUCTIONS
--------------------------------------------------

1. SAP Material ID (M)
   - Type: Alphanumeric | Max Length: 50
   - Example: MAT-456789

2. SAP Material Description (O)
   - Type: Text | Max Length: 100
   - Description of the material

3. SAP NDC (O)
   - Type: Numeric | Max Length: 11
   - Example: 12345678901

4. SP Product ID (M)
   - Type: Alphanumeric | Max Length: 50
   - Unique identifier for the SP product
   - Example: SP-00123

5. SP Product Name (O)
   - Type: Text | Max Length: 100
   - Example: Humira 40mg Injection

6. SP NDC (O)
   - Type: Numeric | Max Length: 11
   - Example: 98765432109

7. Status (M)
   - Type: Text (Value Set) | Max Length: 6
   - Allowed Values:
     - Active
     - Inactive

--------------------------------------------------
✅ SAMPLE ROW:

| SAP Material ID | SAP Material Description | SAP NDC     | SP Product ID | SP Product Name | SP NDC     | Status  |
|-----------------|---------------------------|-------------|----------------|------------------|------------|---------|
| MAT-456789      | Auto Injector             | 12345678901 | SP-00123       | Humira           | 98765432109| Active  |

--------------------------------------------------
NOTES:
- All fields marked (M) must be filled in for a valid upload.
- Status must be either **Active** or **Inactive** (case-sensitive).
- Do not rename or delete template column headers.
- Ensure numeric fields do not contain spaces or special characters.

For support, contact your system administrator.
