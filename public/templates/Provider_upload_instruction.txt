Provider Upload Template - Instructions
==============================================

This template is used to upload Provider records in bulk.

Please follow the field instructions below to avoid upload errors.

Key:
- M = Mandatory (Must be filled)
- O = Optional (Can be left blank)

-------------------------------
FIELD DESCRIPTIONS
-------------------------------

1. First Name (M)
   - Type: Text
   - Max Length: 50 characters
   - Example: John

2. Middle Name (O)
   - Type: Text
   - Max Length: 50 characters
   - Example: A.

3. Last Name (M)
   - Type: Text
   - Max Length: 50 characters
   - Example: Smith

4. DEA Number (M)
   - Type: Text
   - Length: Exactly 9 characters
   - Example: AB1234567

5. NPI Number (M)
   - Type: Number
   - Length: Exactly 10 digits
   - Example: 1234567890

6. Address1 (M)
   - Type: Text
   - Max Length: 100 characters
   - Example: 123 Main St

7. Address2 (O)
   - Type: Text
   - Max Length: 100 characters
   - Example: Suite 101

8. City (M)
   - Type: Alphanumeric
   - Max Length: 50 characters
   - Example: New York

9. Zip (M)
   - Type: Number
   - Max Length: 10 digits
   - Example: 10001

10. State (M)
    - Type: Alphanumeric
    - Max Length: 20 characters
    - Example: NY or New York

11. Phone Number (M)
    - Type: Number
    - Length: Exactly 10 digits (without country code)
    - Example: 2125551234

12. Status (M)
    - Type: Text (Dropdown/Value Set)
    - Accepted Values: Active, Inactive

IMPORTANT NOTES:
-------------------------------
- Do not remove or rename any column headers.
- Ensure all mandatory fields are filled before upload.
- Only use the accepted values for the “Status” field.
- Avoid special characters in numeric fields.
- Ensure NPI and DEA formats are exact.
